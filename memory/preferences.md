## Rules
- **Effort calibration (added 2026-08-23):** Before any task, state recommended effort level (Low / Medium / High / Maximum) with rationale and await confirmation/adjustment before starting. Goal: avoid maximum effort for simple tasks and vice versa.
- **Meta-rule (added 2026-08-23):** Whenever user says "let's add a new rule", persist it to `memory/preferences.md` (personal_project scope) so it survives across sessions.
- **Browser handoff (added 2026-08-23):** After completing a task, if the result is visible/interactive in the browser, tell the user exactly where and how to find it (URL/route, navigation, interaction steps).
- **Logic-focused summary (added 2026-08-23):** After completing a task, describe what changed in terms of logic/behavior (e.g., "I added the compare feature..."), not code mechanics. Still include a brief list of files created/edited.
